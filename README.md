# ZJKVM

**ZJKVM** 是一款运行在浏览器中的 USB KVM 控制台,为 **NanoKVM-USB** 硬件量身打造。它将 HDMI 采集画面与键鼠控制聚合在一个界面中,采用自研的 ZJ 设计语言——暖纸底色、墨色文字、琥珀金点缀——在桌面与移动端提供一致、克制的操作体验。

所有数据处理均在本地浏览器内完成:视频由浏览器直接解码采集卡画面,键鼠指令通过 Web Serial 写入设备,不经任何服务器。

## 功能

**视频**
- 采集卡即插即用,自动识别与热插拔监听
- 预设与自定义分辨率实时切换,最高 4K
- 画面旋转(0°/90°/180°/270°)与缩放(75%–200%)
- 采集卡音频混流,音量与静音控制
- 实时统计浮层:实际分辨率与实测帧率

**键鼠控制**
- 完整键盘转发:物理键盘、屏幕虚拟键盘(含数字小键盘,支持浮窗拖动)
- 绝对 / 相对双模式鼠标,精确坐标映射,支持触屏手势
- 剪贴板逐键输入,支持多行文本与可调速度
- 快捷键组合与序列宏,支持重复执行(适配 BIOS 按键场景)
- LED 状态同步(NUM / CAPS / SCRL)与固件版本回读

**效率工具**
- 画面截图:PNG 下载 + 一键复制到剪贴板
- 屏幕录制:WebM 格式,边录边写盘
- 画中画监视小窗
- 演示模式:无需硬件即可体验完整界面(虚拟采集卡 + 指令可视化回显)
- 简体中文 / English 界面,亮色 / 暗色 / 跟随系统主题
- 设置导出与导入

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 硬件 | NanoKVM-USB(HDMI 采集 + CH9329 HID) |
| 浏览器 | 桌面版 Chrome / Edge(Web Serial 与采集卡访问需要安全上下文) |
| 系统 | macOS / Windows / Linux;移动端浏览器可观看视频并使用触控操作 |

## 工作原理

ZJKVM 与 NanoKVM-USB 通过两条本机通道通信:

- **视频**:采集卡是标准 UVC 设备,浏览器通过 `getUserMedia` 直接解码,支持按 `groupId` 配对同源音频。
- **键鼠**:Web Serial 以 57600 波特率发送 CH9329 兼容指令帧(`57 AB` 帧头 + 校验和),映射为标准 USB HID 报告——键盘 8 字节 Boot 协议、鼠标绝对(12bit)/ 相对(±127)两种模式。
